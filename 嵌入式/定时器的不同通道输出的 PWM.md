# 一句话核心

**同一个定时器的所有通道，共用 1 个时基单元（同一个计数器 CNT、PSC、ARR）** 所以：**所有通道 PWM 频率完全相同；占空比各自独立由自己的 CCR 寄存器控制；计数动作天然同步。**

## 1. 频率周期全部一样

时基单元：`CNT计数器 + PSC预分频 + ARR自动重装载`，整个定时器只有**一套**。 计数器从头计数到 ARR，溢出，这就是 PWM 周期。 TIM2_CH1、CH2、CH3、CH4 全都看这同一个 CNT。 → 4 个通道 PWM 周期 = 1/(CK_PSC/(PSC+1)/(ARR+1))，**频率一模一样，无法单独改某一路的频率**

> 想不同频率 PWM：要用**不同的定时器**（TIM2、TIM3 分开）

## 2. 占空比：各通道独立，由各自 CCR 决定

每个通道有独立的 CCR 捕获比较寄存器：

- CH1 → CCR1
- CH2 → CCR2
- CH3 → CCR3
- CH4 → CCR4

CNT 不断往上计数： 每当 `CNT == CCRx`，就翻转对应通道的 OCxREF 参考信号。 ARR 决定周期，CCRx 决定**什么时候翻转**。 公式：占空比 = CCRx / (ARR+1)

👉 同一定时器：频率统一，**四路占空比可以随便单独设置，互不干扰**。 例：ARR=999 CCR1=250 → 25% 占空比 CCR2=500 → 50% 占空比 CCR3=750 →75% 占空比

## 3. 相位天然同步

计数器是同一个起点，CNT 从 0 同时开始往上数。

- CNT=0，所有通道一起从零开始
- CNT=250，CH1 触发翻转
- CNT=500，CH2 触发翻转

所以各路 PWM**起点对齐，相位关系固定可控**。 你可以通过设置不同 CCR，做出带相位差的多路 PWM（比如移相 PWM、H 桥、多电机驱动）。
