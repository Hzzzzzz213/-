# 逐行通俗讲解这段按键扫描函数

```
uint8_t Key_GetNum(void)
{
	uint8_t KeyNum = 0;		//定义变量，默认键码值为0
```

`KeyNum=0`含义：**默认没有按键按下**，0 是函数返回给主函数的消息，和引脚电平无关。

```
	if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0)			
	//读取PB1引脚电平，等于0 → 引脚低电平（按键按下，引脚是上拉输入）
	{
		Delay_ms(20);											//延时消抖，机械按键按下瞬间电平会抖动，等20ms稳定
		while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0);	
		// while循环：只要引脚还是0，就一直卡在这，【等待松手】，不往下执行
		Delay_ms(20);											//松手再次消抖
		KeyNum = 1;												//标记：本次是按键1触发
	}
```

```
	if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0)			
	//检测PB11按键
	{
		Delay_ms(20);											
		while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0);	//等待按键2松手
		Delay_ms(20);											
		KeyNum = 2;												//标记：本次是按键2触发
	}
```

```
	return KeyNum;			//返回键码：0无按键 /1按键1 /2按键2
}
```

## ✅ 核心特点

1. **松手触发** 不是按下瞬间就返回，**必须等手松开，函数才会带出键值**。 按下按键的时候，程序卡在`while`里面原地等待，松手之后才继续跑。
2. 上拉输入逻辑再回顾 引脚配置`GPIO_Mode_IPU`上拉输入：

- 没按 → 高电平，读到`1`，不进 if
- 按下 → 引脚接地，读到`0`，进入 if 执行

## ⚠️ 代码缺陷（考试 / 写代码重点）

1. **不能检测长按**，只能检测按下松开一次触发一次
2. **不支持多按键同时按下**：两个按键一起按，后面的 KeyNum 会覆盖前面
3. 阻塞式：`while`等待松手，**程序卡在这，别的代码无法运行**（主循环会被卡住）

## 使用示例（主函数调用）

```
uint8_t num;
num = Key_GetNum();
if(num ==1)
{
	//按键1按下松开后执行
}
if(num ==2)
{
	//按键2按下松开后执行
}
```
