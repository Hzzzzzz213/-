# 为什么传两个实参：`TIM2` 和 `&TIM_TimeBaseInitStruct`

```
void TIM_TimeBaseInit(TIM_TypeDef* TIMx, TIM_TimeBaseInitTypeDef* TIM_TimeBaseInitStruct);

TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStruct);
```

函数有**两个指针形参**，两个参数给函数提供两类完全不同信息。

## 参数 1：`TIM2` → 传给形参 `TIM_TypeDef* TIMx`

- `TIM2` 是宏，展开：`((TIM_TypeDef *)0x40000000U)`
- 它是**定时器硬件寄存器的指针（硬件地址）**

👉 告诉函数：**你要操作哪一个定时器硬件（TIM2）**。

函数内部靠 `TIMx->PSC`、`TIMx->ARR` 访问 TIM2 的寄存器。

> TIM1 / TIM2 / TIM3 / TIM4 都可以选，所以必须传这个参数。

> TIM2 本身已经是指针，**不要加 &**。

## 参数 2：`&TIM_TimeBaseInitStruct` →传给形参 `TIM_TimeBaseInitTypeDef* TIM_TimeBaseInitStruct`

- `TIM_TimeBaseInitStruct` 是你写在代码里、存放在**RAM 栈上的配置结构体变量**。
- `&`：取这个结构体变量的内存地址。

👉 告诉函数：**到 RAM 内存这个地址，读取我填好的 PSC、ARR、计数模式等全套配置参数**。

函数内部读取这个结构体里面每一个成员，再赋值给 TIM2 硬件寄存器。


## 函数内部伪代码


```
void TIM_TimeBaseInit(TIM_TypeDef* TIMx, TIM_TimeBaseInitTypeDef* TIM_TimeBaseInitStruct)
{
    // TIMx = TIM2：确定操作哪套硬件寄存器
    // TIM_TimeBaseInitStruct：指向RAM中我们写的配置表格

    TIMx->PSC = TIM_TimeBaseInitStruct->TIM_Prescaler;
    TIMx->ARR = TIM_TimeBaseInitStruct->TIM_Period;
    TIMx->CR1 |= TIM_TimeBaseInitStruct->TIM_CounterMode;
    //……把结构体全部成员，写到TIM2硬件寄存器
}
```

### 类比

> 函数 = 办事员
> 
> - `TIM2` = 要改造的房间编号（硬件）
> - `&TIM_TimeBaseInitStruct` = 放在你桌上的配置申请表的地址（RAM 内存里的表格）
> 
> 办事员拿到房间号，再跑到你桌上读取申请表，按申请表修改房间内部设施。

## 补充
- `TIM2`：宏，硬件指针常量，本身就是地址，**不加 &**
- `TIM_TimeBaseInitStruct`：RAM 栈上普通结构体变量，变量不是地址，**必须 & 取地址传给指针形参**。
