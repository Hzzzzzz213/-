# STM32 GPIO 常用寄存器（F1系列，最经典）

> 每个GPIO端口（GPIOA/GPIOB/GPIOC…）都有下面这一组寄存器，32位

## 1. CRL / CRH 配置寄存器（端口模式寄存器）

- **CRL：端口低配置寄存器** → Pin0 ~ Pin7
- **CRH：端口高配置寄存器** → Pin8 ~ Pin15
- 每4bit控制1个引脚：`MODE[1:0]`（速度）+ `CNF[1:0]`（模式：推挽/开漏/输入/复用）
- 作用：**设置引脚是输入还是输出、推挽还是开漏、上拉下拉**
    
    > F4以后版本叫 `MODER`、`OTYPER`，不再是CRL/CRH
    

## 2. IDR 输入数据寄存器 Input Data Register

- 只读
- 低16位对应Pin0~Pin15
- 读IDR，拿到引脚外部真实电平：bit=1 高电平，bit=0 低电平
- ✅ 输入模式用：按键检测、外部信号读取

```
if(GPIOB->IDR & GPIO_Pin_0){} // 判断PB0是否为高
```

## 3. ODR 输出数据寄存器 Output Data Register

- 可读可写，低16位对应Pin0~Pin15
- 写ODR：设置输出电平；bit=1高，bit=0低

```
GPIOB->ODR ^= GPIO_Pin_5; // PB5电平翻转
```

⚠️ 缺点：读改写，多任务下有竞态风险

## 4. BSRR 置位/复位寄存器 Bit Set/Reset Register

- **只写寄存器！**
- 低16位 `BS[15:0]`：写1 → 对应引脚置高（Set）
- 高16位 `BR[31:16]`：写1 → 对应引脚清零（Reset）
- ✨ 优点：**没有读改写风险，推荐优先用BSRR控制引脚**

```
GPIOB->BSRR = GPIO_Pin_5;        // PB5置高
GPIOB->BSRR = (uint32_t)GPIO_Pin_5 << 16; // PB5置低
```

## 5. BRR 复位寄存器 Bit Reset Register

- 只写
- 低16位，写1 → 引脚清零
- 功能等价于BSRR的高16位，单独用来拉低引脚

```
GPIOB->BRR = GPIO_Pin_5; // PB5拉低
```

## 6. LCKR 锁定寄存器 Lock Register

- 锁定引脚配置，锁定后CRL/CRH不能再修改，防止误改配置
- 配置锁序列比较特殊，一般很少用

# 其他片上外设高频寄存器（不止GPIO）

### RCC 复位时钟（重中之重）

- `RCC->APB2ENR`：APB2外设时钟使能（GPIOA/B/C、USART1、ADC等）

```
RCC->APB2ENR |= RCC_APB2ENR_IOPBEN; // 开启GPIOB时钟
```

- `RCC->APB1ENR`：APB1外设时钟（USART2/3、TIM2~TIM7、I2C、SPI2）
- `RCC->CFGR`：时钟配置，分频、时钟源选择

### 定时器 TIM

- `TIMx->CR1`：控制寄存器1（使能计数器、向上/向下计数）
- `TIMx->ARR`：自动重装载值（周期）
- `TIMx->PSC`：预分频器
- `TIMx->CNT`：计数器当前值
- `TIMx->CCR1/CCR2`：捕获比较寄存器（PWM占空比）

### USART串口

- `USARTx->SR`：状态寄存器（TXE发送空、RXNE接收标志）
- `USARTx->DR`：数据寄存器（收发数据）
- `USARTx->BRR`：波特率设置

# 快速对比表（GPIO核心4个）

|寄存器|读写|用途|
|---|---|---|
|CRL/CRH|读写|引脚模式配置（输入/输出/复用）|
|IDR|只读|读取引脚外部电平（输入）|
|ODR|读写|设置输出电平，可翻转|
|BSRR|只写|置高、拉低引脚，无读改写风险|

> 小总结：
> 
> - 配置引脚：CRL/CRH
> - 读引脚电平：IDR
> - 输出控制：优先BSRR；想要翻转用ODR异或
