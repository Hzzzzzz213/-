•Encoder Interface 编码器接口

•编码器接口可接收增量（正交）编码器的信号，根据编码器旋转产生的正交信号脉冲，自动控制CNT自增或自减，从而指示编码器的位置、旋转方向和旋转速度

•每个高级定时器和通用定时器都拥有1个编码器接口

•两个输入引脚借用了输入==捕获的通道1和通道2==

==**编码器接口模式基本上相当于使用了一个带有方向选择的外部时钟。**==

1. **CNT 加 / 减由编码器决定** 开启编码器模式后： 编码器 A、B 相的边沿，直接控制 CNT +1 或者 -1。 👉 **CNT 计数的触发源 = 编码器信号**
2. **定时器本身硬件电路运行，靠内部时钟** TIM3 寄存器、滤波电路这些硬件，依然需要 APB1 内部时钟来驱动工作。 内部时钟只负责让定时器硬件能正常跑，**不再用来让 CNT 自增**（普通定时模式才是内部时钟让 CNT 往上加）。

### 编码器代码
TIM_EncoderInterfaceConfig(TIM3, TIM_EncoderMode_TI12, TIM_ICPolarity_Rising, TIM_ICPolarity_Rising);
//配置编码器模式以及两个输入通道是否反相
//注意此时参数的Rising和Falling已经不代表上升沿和下降沿了，而是代表是否反相
//此函数必须在输入捕获初始化之后进行，否则输入捕获的配置会覆盖此函数的部分配置


TIM_TimeBaseInitTypeDef TIM_TimeBaseInitStructure;				<font color="#2DC26B">//定义结构体变量</font>
	TIM_TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;     <font color="#2DC26B">//时钟分频，选择不分频，此参数用于配置滤波器时钟，不影响时基单元功能</font>
	TIM_TimeBaseInitStructure.TIM_CounterMode = TIM_CounterMode_Up; //<font color="#00b050">计数器模式，选择向上计数,</font><font color="#ff0000">计数方向被编码器托管，没有作用</font>
	TIM_TimeBaseInitStructure.TIM_Period = 65536 - 1;            <font color="#00b050"> <font color="#00b050">  //<font color="#ff0000">计数周期，即ARR的值</font></font>计数范围最大，方便换算成负数</font>
	TIM_TimeBaseInitStructure.TIM_Prescaler = 1 - 1;                <font color="#00b050">//预分频器，即PSC的值，不分频，编码器时钟直接驱动计数器</font>
	TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0;            <font color="#00b050">//重复计数器，高级定时器才会用到</font>
	TIM_TimeBaseInit(TIM3, &TIM_TimeBaseInitStructure);             <font color="#00b050">//将结构体变量交给TIM_TimeBaseInit，配置TIM3的时基单元</font>


/*输入捕获初始化*/

	TIM_ICInitTypeDef TIM_ICInitStructure;							//定义结构体变量
	TIM_ICStructInit(&TIM_ICInitStructure);							//结构体初始化，若结构体没有完整赋值则最好执行此函数，给结构体所有成员都赋一个默认值避免结构体初值不确定的问题
	TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;				//选择配置定时器通道1
	TIM_ICInitStructure.TIM_ICFilter = 0xF;							//输入滤波器参数，可以过滤信号抖动
	TIM_ICInit(TIM3, &TIM_ICInitStructure);							//将结构体变量交给TIM_ICInit，配置TIM3的输入捕获通道
	
	
	TIM_ICInitStructure.TIM_Channel = TIM_Channel_2;				//选择配置定时器通道2
	TIM_ICInitStructure.TIM_ICFilter = 0xF;							//输入滤波器参数，可以过滤信号抖动
	TIM_ICInit(TIM3, &TIM_ICInitStructure);							//将结构体变量交给TIM_ICInit，配置TIM3的输入捕获通道


**结构体变量只有 1 个，重复修改里面成员，然后重新传给 TIM_ICInit；不用新建第二个结构体。**

1. `TIM_ICInitStructure` 就这**一个结构体内存空间**
    - 先给通道 1 赋值 → 调用`TIM_ICInit`，把当前结构体里的配置写入 TIM3 通道 1 硬件
    - 接着**直接覆盖修改结构体成员**（改成通道 2 的参数）
    - 再次调用`TIM_ICInit`，把新的这一组配置写入 TIM3 通道 2 硬件

> 上一次通道 1 的配置已经写到寄存器里了，结构体本身只是临时存放参数，写完硬件后结构体里面的值就没用了，可以直接覆盖。

==重点 `TIM_ICInit`函数的作用：**读取结构体里面的参数，写到外设寄存器**。 写完之后，结构体和硬件就断开关系了，结构体只是个临时参数载体，结构体的值后续改变**不会自动影响硬件**。==

## 中断函数
void TIM2_IRQHandler(void)
{
	if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)		//判断是否是TIM2的更新事件触发的中断
	{
		Speed = Encoder_Get();								//每隔固定时间段读取一次编码器计数增量值，即为速度值
		TIM_ClearITPendingBit(TIM2, TIM_IT_Update);			//清除TIM2更新事件的中断标志位
															//中断标志位必须清除
															//否则中断将连续不断地触发，导致主程序卡死
	}
}
==TIM3 的 CNT：由编码器 A/B 相脉冲驱动（编码器接口模式，CNT 随编码器正反转增减）==
==TIM2 的 CNT：由系统 APB1 定时器时钟驱动，用来定时产生更新中断，每隔固定时间读取一次 TIM3 的 CNT 值，用来算速度==
