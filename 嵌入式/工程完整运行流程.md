# 整套工程完整运行流程（main.c/ LED.c/ LED.h 拆解）

先记住核心分工：

- **LED.h**：函数声明，只告诉编译器「有这个函数」
- **LED.c**：`LED_Init()` 硬件初始化**实体代码**
- **main.c**：程序入口，调用初始化、死循环

## 一、三个文件各自作用

### 1. LED.h（头文件，对外接口）

c

运行

```
#ifndef __LED_H
#define __LED_H
void LED_Init(void);
#endif
```

1. `#ifndef‑#define‑#endif`：头文件保护，防止多次 `#include` 重复报错
2. `void LED_Init(void);`
    
    **函数声明**：仅告知编译器，存在一个无返回、无参数的初始化函数；
    
    **这里没有函数执行代码**，实现放在 LED.c。

### 2. LED.c（LED 初始化实现）

c

运行

```
#include "stm32f10x.h"

void LED_Init(void)
{
	// 1.开启GPIOA端口时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
	
	// 2.定义GPIO初始化结构体
	GPIO_InitTypeDef GPIO_InitStructure;
	
	// 3.配置为推挽输出（普通高低电平控制LED）
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
	// 选中 PA1、PA2引脚
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_1 | GPIO_Pin_2;
	// IO口速度50MHz
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	
	// 4.把配置写入GPIOA寄存器，完成引脚初始化
	GPIO_Init(GPIOA, &GPIO_InitStructure);
}
```

逐行功能：

1. STM32 外设**默认时钟关闭**，必须先开启 GPIOA 时钟，引脚才可以工作
2. 结构体用来一次性配置引脚模式、引脚编号、IO 速度
3. `GPIO_Mode_Out_PP`：推挽输出，可以输出高 / 低电平驱动 LED
4. `GPIO_Pin_1 | GPIO_Pin_2`：同时配置 PA1、PA2 两个引脚
5. `GPIO_Init()`：把结构体参数写入芯片寄存器，硬件正式配置完成

### 3. main.c 主函数入口

c

运行

```
#include "stm32f10x.h"
#include "LED.h"

int main(void)
{
	LED_Init();
	
	while (1)
	{

	}
}
```

1. `#include "LED.h"`
    
    把 LED 头文件导入，编译器就认识 `LED_Init()` 这个函数
2. 程序上电后，最先进入 `main()`
3. 先执行 `LED_Init();` → 跳转运行 LED.c 里面的初始化代码，配置好 PA1、PA2 输出引脚
4. `while(1)` 无限死循环
    
    单片机程序不能跑完就结束，循环在这里原地等待；
    
    你后续点亮、熄灭 LED 的代码就写在这个 while 循环内部

# 二、完整从上电到运行的完整流程

1. 单片机上电 → 系统先执行底层启动文件，初始化堆栈
2. 自动跳转到 `main()` 主函数
3. main 里面调用 `LED_Init()`
4. 进入 LED.c 的初始化函数：
    
    - 打开 GPIOA 时钟
    - 设置 PA1、PA2 为推挽输出模式
    - 硬件引脚配置完毕
    
5. 初始化结束，回到 main 函数
6. 进入 `while(1)` 永久循环，程序停在这里

> 现在你的代码只做了**引脚初始化**，还没有设置引脚高低电平，LED 不会亮；
> 
> 需要在 while 循环添加：
> 
> c
> 
> 运行
> 
> ```
> GPIO_SetBits(GPIOA,GPIO_Pin_1);   //输出高电平
> GPIO_ResetBits(GPIOA,GPIO_Pin_1); //输出低电平
> ```
