•DMA（Direct Memory Access）直接存储器存取

•DMA可以提供外设和存储器或者存储器和存储器之间的高速数据传输，无须CPU干预，节省了CPU的资源

•12个独立可配置的通道： DMA1（7个通道）， DMA2（5个通道）

•每个通道都支持软件触发和特定的硬件触发

### 外设可以看成==寄存器==，是SRAM存储器
1.CPU可以对寄存器进行读写
2.寄存器的每一位都连接一根导线，导线可以控制外设的状态，引脚高低电平，导通断开开关，切换数据选择器，多位结合起来，当作数据寄存器.计数器等


![[DMA-3.png]]
- ✅ 地址自增开启：传完一个，地址 + 1，下一次读 / 写下一个位置 例：SRAM 数组 `buf[0],buf[1],buf[2]`，传完 buf [0]，自动跳到 buf [1]，适合连续数组
- ❌ 地址自增关闭：地址固定不变，永远读 / 写同一个位置 例：ADC 一直往同一个变量存采样值；或者一直往串口 DR 寄存器发数据（外设寄存器地址固定）

- **软件触发**：人写代码手动开一次。适合内存拷贝，M2M 模式专用。
- **硬件触发**：外设事件自动启动（ADC 转换完成、串口收到数据），适用于存储器到存储器，不能和自动重装器一起使用

  ==写入传输计数器时要关闭DMA_cmd==

# ADC扫描模式 + DMA 重点（结合图）


## 1. ADC扫描模式

- 提前配置**规则序列**：图里序列1~7依次是通道2、5、4、1、0、3、6
- 收到1次触发信号 → ADC自动按序列顺序挨个转换通道，不用CPU切换通道
- 每转换完**1个通道**，产生EOC标志，同时触发DMA搬运

## 2. DMA地址配置（核心考点）

1. **DMA外设地址 = ADC_DR（固定不变！外设地址不自增）** 所有通道的转换结果，都先放在这同一个寄存器。
2. **DMA存储器地址 = SRAM数组ADValue，开启存储器地址自增** 搬完一个数据，数组地址+2（uint16_t），依次存入数组第0、1、2……号元素
    
    > 对应图：通道2结果放ADValue[0]，通道5放ADValue[1]……通道6放ADValue[6]
    

## 3. 传输流程

1. 触发信号来了（定时器触发最常用）
2. ADC转换序列1（通道2），转换完成 → EOC，触发DMA
3. DMA把ADC_DR的数据搬到`ADValue[0]`
4. ADC自动切换到序列2（通道5），转换完成 → 再次触发DMA，存入`ADValue[1]`
5. 一直循环，直到7个通道全部采集、全部存入数组

## 4. 关键配置要点

- ADC：开启**扫描模式**；配置好规则组序列（顺序自己定义）
- DMA：外设地址不自增，存储器地址自增；数据宽度16位
- 触发源：一般用定时器硬件触发，周期性自动采集
- 传输计数：填通道总数量（本例7），7个全部传完，可触发DMA传输完成中断
