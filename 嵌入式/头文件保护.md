运行

```
#ifndef __LED_H
#define __LED_H

void LED_Init(void);

#endif
```

## 1、逐个单词翻译

- `#ifndef` = **if not defined**：如果宏没有被定义
- `#define __LED_H`：定义名叫 `__LED_H` 的宏
- `#endif`：结束 if 判断

## 2、它到底干什么

防止**同一个头文件被多次 #include 包含**，造成重复定义报错。

### 举个现实场景

main.c 包含 LED.h

c

运行

```
#include "LED.h"
```

中途你别的文件又再次包含 LED.h

c

运行

```
#include "LED.h"
```

### 第一次载入 LED.h

1. `#ifndef __LED_H`
    
    现在 `__LED_H` 不存在 → 条件成立，往下执行
2. `#define __LED_H`
    
    打上标记：这个头文件已经来过一次
3. 读取 `void LED_Init(void);` 函数声明

### 第二次再次载入 LED.h

1. `#ifndef __LED_H`
    
    `__LED_H` 已经被第一次定义过 → **条件不成立**
2. 直接跳过中间全部代码，不会重复读取函数声明

---

## 3、大白话比喻

`__LED_H` 相当于一个门牌标记

1. 第一次进门：门上没标记 → 贴上门牌，然后进门加载函数声明
2. 之后再来敲门：门牌已经存在，直接不让你进门，防止代码重复加载

## 4、为什么名字写成 `__LED_H`

- 双下划线：用来避开你自己写的普通变量、宏，防止名字撞车
- 命名习惯：`__文件名_H`

## 5、不加头文件保护会发生什么

多个文件同时包含 LED.h，编译器会多次读到

`void LED_Init(void);`

报 **重复重定义错误**。
