# NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);

c

运行

```
void NVIC_PriorityGroupConfig(uint32_t NVIC_PriorityGroup);
```

**功能：设置中断优先级分组，整个芯片只设置一次，写在 main 最开头。**

## NVIC_PriorityGroup_2 含义

- **抢占优先级：2 位，取值 0~3**（数字越小优先级越高）
- **子优先级：2 位，取值 0~3**

> 总共 4 位优先级，分成 2 位抢占，2 位子。

1. **抢占优先级（主优先级）：可以插队**
    
    如果正在执行一个中断，**来了一个抢占优先级更高的中断**，新的中断可以直接打断当前正在跑的中断，先执行自己。

> 例：抢占优先级 0 > 抢占优先级 2。
> 
> 正在跑抢占 2 的中断，抢占 0 来了，直接把它打断，先跑抢占 0。

2. **子优先级（响应优先级）：不能插队，只管同时到达谁先跑**
    
    子优先级**不能打断正在运行的中断**。
    
    只有好几个中断**同一时刻一起过来**的时候，子优先级数字小的，优先先执行。
### Group2 参数速记



|分组|抢占优先级|子优先级|
|---|---|---|
|NVIC_PriorityGroup_2|2 位 (0‑3)|2 位 (0‑3)|



```
NVIC_InitTypeDef NVIC_InitStructure;
NVIC_InitStructure.NVIC_IRQChannel = EXTI15_10_IRQn;
NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1; //抢占优先级
NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;         //子优先级
NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
NVIC_Init(&NVIC_InitStructure);
```

## ⚠️重要考点

1. `NVIC_PriorityGroupConfig()` **整个程序只调用一次**，一般放在 main 开头。多次调用会出错。
2. 分组一旦定好，后面写`PreemptionPriority`、`SubPriority`就必须遵守这个分组位数。
3. Group2：抢占最大写 3，子优先级最大写 3，不能写 4。
