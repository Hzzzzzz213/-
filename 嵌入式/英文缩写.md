# PU‑Input Pull‑UP 上拉输入 完整解析

## 1、缩写释义

- **IPU** = Input Pull‑Up
- 中文：**上拉输入模式**，是 STM32 单片机 GPIO 最常用输入模式之一

## 2、工作原理

GPIO 引脚内部接通上拉电阻（STM32‑F103 内置约 30‑50KΩ 上拉电阻）

1. 引脚悬空：引脚电平被内部电阻拉高 → **默认高电平**
2. 引脚外接 GND（接地）：引脚被拉低 → 低电平

> 用来读取按键信号最为适配：按键一端接引脚、一端接地，没按下为高电平，按下后变成低电平


## 4、按键配置示例（标准库）

c

运行

```
// PA0 上拉输入
GPIO_InitTypeDef gpio_conf;
GPIO_Init(GPIOA,&gpio_conf);
gpio_conf.GPIO_Pin = GPIO_Pin_0;
gpio_conf.GPIO_Mode = GPIO_Mode_IPU; // 设置上拉输入
GPIO_Init(GPIOA,&gpio_conf);
```

### 🚦 第一类：系统控制类（芯片的“电网和交警”）

- **RCC（复位和时钟控制）**：芯片的“总电闸和节拍器”。你之前问的**使能函数**，就是操作它里面的开关。**每个外设使用前必须在这里开时钟。**
    
- **NVIC（嵌套向量中断控制器）**：处理中断优先级的“大管家”。比如串口收到数据、定时器溢出，都由它决定先响应谁。
    
- **SysTick（系统滴答定时器）**：内核自带的“心跳定时器”，通常用来做**精准延时**（比如`HAL_Delay()`就是靠它实现的）。
    
- **EXTI（外部中断）**：把GPIO引脚和中断系统连接起来的“门铃”。按键按下触发中断，就是走的这个通道。
    
- **AFIO（复用IO口）**：GPIO的“功能切换开关”。比如PA9，你可以设为普通IO，也可以切换成USART1的TX发送脚，由这个模块控制。
    
- **PWR（电源控制）**：控制芯片进入睡眠、停机等低功耗模式，省电用的。
    

### 💾 第二类：存储与搬运类（芯片的“仓库和快递员”）

- **Flash（闪存，图中未列出但核心存在）**：存固件的“硬盘”，断电不丢失。
    
- **SRAM（内存，图中未列出但核心存在）**：存变量的“内存条”，断电即失。
    
- **DMA（直接内存访问）**：**外设界的“专业快递员”**。比如ADC采集数据，DMA可以自动把数据搬运到内存数组里，完全不消耗CPU资源。
    

### 🕹️ 第三类：定时与控制类（芯片的“闹钟和安保”）

- **TIM（定时器）**：从简单的延时、到精密的PWM波输出（控制电机转速）、再到捕获外部脉冲的宽度，**TIM是STM32使用频率最高的外设之一**。
    
- **IWDG / WWDG（独立看门狗 / 窗口看门狗）**：芯片的“保安”和“巡警”。如果你的程序跑飞了，没有按时“喂狗”（重置计时器），它们就会强行复位芯片，防止系统死机。
    

### 📡 第四类：通信接口类（芯片的“嘴巴和耳朵”）

- **USART / UART（同步/异步串口）**：最常用的调试和通信手段。用于和电脑串口助手、蓝牙模块、GPS模块通信。
    
- **I2C**：通常用于连接**温湿度传感器（如AHT20）**、**OLED屏幕**、或**EEPROM存储器**（两线制）。
    
- **SPI**：高速通信接口，用于连接**TFT彩屏**、**Flash存储芯片（如W25Q64）**、或者**高速ADC**。
    
- **CAN（控制器局域网络）**：汽车电子和工业控制常用，抗干扰能力强，支持多个设备挂在同一条总线上通信。
    
- **USB**：用于和电脑进行USB通信。C8T6型号只有USB从设备（Device）功能，不支持主机模式（USB OTG）。
    

### ⚡ 第五类：模拟信号处理类（芯片的“耳朵”和“喇叭”）

- **ADC（模数转换器）**：把真实的电压（如0~3.3V）转成数字（如0~4095），用来读取**光敏电阻、电位器、电池电压**。
    
- **DAC（数模转换器）**：把数字转成模拟电压，用来输出**正弦波、音频信号**等（C8T6没有DAC，F103系列中只有大容量型号才有）。
