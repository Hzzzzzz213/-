•IC（Input Capture）输入捕获

•输入捕获模式下，当通道输入引脚出现指定电平跳变时，当前CNT的值将被锁存到CCR中，可用于测量PWM波形的频率、占空比、脉冲间隔、电平持续时间等参数

•每个高级定时器和通用定时器都拥有4个输入捕获通道每个通道的输入捕获和输出比较只能用一个

•可配置为PWMI模式，同时测量频率和占空比

•可配合主从触发模式，实现硬件全自动测量

## 1. CNT 转运到 CCR 是什么意思

> CCR = Capture/Compare Register，**捕获 / 比较寄存器**

- **CNT**：定时器计数器，一直在`CK_CNT`时钟驱动下持续递增（向上计数模式）。
- 当 TIM 通道配置为**输入捕获模式**时： 外部信号（TIMx_CHx）的指定边沿（上升沿 / 下降沿）到来，硬件自动把**当前 CNT 计数器的值，瞬间拷贝存入 CCR 寄存器**。 这个动作就是：**CNT 转运到 CCR**，全程硬件自动完成，不需要 CPU 干预。 同时会置捕获中断标志，触发中断通知 CPU 来读取 CCR 里面存下的计数值。

> 简单一句话：**捕获边沿来了，硬件锁存此刻 CNT 的计数值到 CCR 保存起来。**

## 2. 测周法测频率
### 配合你图里的流程（单次捕获中断清 CNT 方案）

1. TIM 通道配置为**上升沿捕获**；定时器向上计数。
2. 第一个上升沿到来：硬件把 CNT 存入 CCR，进入捕获中断；
3. 在中断服务函数里，**直接把 CNT 清零**；
4. 等待下一个上升沿：再次触发捕获，硬件把当前 CNT（就是这一个周期里的计数值 N）存入 CCR；
5. 读取 CCR 得到 N，代入公式计算信号频率。

> 两个上升沿之间，就是被测信号**一个周期**；CNT 从 0 计数到 N，N 就是这个周期内定时器计数脉冲个数。

# 输入捕获基本结构

![[输入捕获-6.png]]1. 外部脉冲从 GPIO 进来，先滤波去毛刺，再检测上升沿
2. **一旦检测到上升沿（TI1FP1）**，同时做两件硬件动作：
    - ① 捕获：把当前 CNT 的值，存入 CCR1
    - ② 复位：触发从模式 Reset，**硬件直接把 CNT 清零**
3. CNT 清零后，重新从 0 开始往上计数，等待下一个上升沿

波形含义： 每次上升沿，CCR1 锁存这一整个周期的计数值，CNT 归零。 👉 直接读 CCR1，就能算出**信号周期**。

# PWMI基本结构

![[输入捕获-7.png]]


1. 一路 PWM 信号进 GPIO，先滤波去毛刺，边沿检测后**分成两路 TI1FP1、TI1FP2**，送给同一个定时器的两个捕获通道。

- TI1FP1：==**上升沿**触发 CCR1 捕获，同时触发从模式 Reset，硬件把 CNT 清零==
- TI1FP2：==<font color="#2DC26B">**下降沿**触发 CCR2 捕获</font>==

2. 硬件动作：

- 上升沿：CNT 存入 CCR1 → CNT 清零，CCR1 的值 = PWM**整个周期**的计数值
- 下降沿：CNT 存入 CCR2，CCR2 的值 = PWM**高电平**的计数值

3. 特点

- 只用**1 个外部引脚**，占用定时器**2 个通道**
- 硬件自动清零 CNT，不用软件处理溢出
- 一次同时==读出周期、高电平时间，直接算频率 + 占空比==

一句话： PWMI 把一路 PWM 分出两路边沿信号，上升沿抓 CCR1（周期）并复位 CNT，下降沿抓 CCR2（高电平），专门用来测量 PWM 波形。
