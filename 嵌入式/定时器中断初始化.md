# TIM2 定时中断初始化 记忆套路

整体流程口诀：**开时钟 → 选时钟源 → 配置时基单元 → 配置定时器中断 → 配置 NVIC 内核 → 打开定时器开始跑**

> 硬件通路对照框图：RCC 时钟 → 时钟源选择器 (内部时钟) → PSC 预分频 → CNT 计数器 + ARR → 更新中断 → 中断输出控制 → NVIC

## ① 开启外设时钟（必做，所有外设第一步）

```
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
```

记忆：TIM2 在 APB1 总线上，先给定时器供电，不开启时钟定时器完全不工作。

## ② 选择定时器时钟源

```
TIM_InternalClockConfig(TIM2);
```

框图最左边多路选择器，选「内部时钟模式」，**不写也默认内部时钟，写出来更清晰**。

> 其他选项：ETR 外部时钟、ITRx 其他定时器、TIx 捕获通道、编码器模式。

## ③ 时基单元初始化（PSC、ARR、计数模式）

```
TIM_TimeBaseInitTypeDef 结构体;
//1.时钟分频CKD：只给输入捕获滤波器用，定时中断直接写DIV1，不用管
//2.计数模式：向上计数，最常用
//3.TIM_Period = ARR‑1
//4.TIM_Prescaler = PSC‑1
//5.RepetitionCounter：只有高级定时器TIM1/TIM8用，通用定时器写0
TIM_TimeBaseInit(TIM2, &结构体);
```

✅记忆点：

1. `TIM_ClockDivision` **不影响定时时间**，只管输入滤波，定时中断无脑填`TIM_CKD_DIV1`。
2. `ARR`、`PSC`全部**寄存器值 = 需要的值 −1**，计数器从 0 开始计数。
3. `RepetitionCounter`重复计数器：**通用定时器直接写 0，不用管**，高级定时器才生效。

## ④ 定时器外设侧中断配置（定时器自己的中断开关）

```
TIM_ClearFlag(TIM2, TIM_FLAG_Update);    //清标志，防止一开中断立刻进一次
TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE); //打开更新中断
```

记忆两步：

1. **清更新标志位**：`TIM_TimeBaseInit`内部会产生更新事件，标志会被硬件置 1；不清，一开启中断就马上进一次中断服务函数。
2. `TIM_ITConfig`：**外设层中断开关**。相当于定时器内部的闸门，闸门不开，就算 CNT 计数溢出，也发不出中断信号给 NVIC。

> 区分：`TIM_FLAG_Update`是标志；`TIM_IT_Update`是中断使能。

## ⑤ NVIC 内核配置（内核的中断控制器）

```
NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2); //全局只调用1次！！！
NVIC_InitTypeDef NVIC_InitStructure;
NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;
NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 2;
NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;
NVIC_Init(&NVIC_InitStructure);
```

重点坑：

1. `NVIC_PriorityGroupConfig` **整个工程只能调用一次**，放在 main，不要写在 Timer_Init！多次调用会覆盖分组。作用：设置 NVIC 优先级分组，划分抢占优先级、响应优先级所占位数。
2. `TIM2_IRQn` 是 TIM2 对应的中断通道，不同定时器名字不一样：TIM1_IRQn、TIM3_IRQn。
3. 两个优先级：抢占优先级 > 响应优先级。

> 框图右侧：中断输出控制输出信号，给到 NVIC 内核。**先配置外设定时器，再配置 NVIC 内核，顺序不能颠倒。**

## ⑥ 使能定时器，开始计数（最后一步！）

```
TIM_Cmd(TIM2, ENABLE);
```

全部配置写完，最后打开定时器，CNT 计数器才开始跑。

## ⑦ 中断服务函数模板（写 main 外面）

```
void TIM2_IRQHandler(void)
{
	if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
	{
		//这里写定时到要执行的代码
		
		TIM_ClearITPendingBit(TIM2, TIM_IT_Update); //必须清除挂起位
	}
}
```

记忆：先判断中断标志，**最后一定要清除中断挂起位，否则会一直进中断**。

# 极简记忆口诀（背诵）

1. **开 RCC 时钟，给定时器上电**
2. **选时钟源（内部时钟）**
3. **时基结构体：CKD 随便、向上计数、ARR-1、PSC‑1，重复计数写 0，调用 Init 写入硬件**
4. **清更新标志，TIM_ITConfig 打开定时器更新中断**
5. **NVIC 配置：全局分组只写一次，填对应 IRQ 通道，设置优先级**
6. **TIM_Cmd 使能定时器，放在最后**
7. **中断函数里：判断 IT 状态，干活，清除中断挂起位**

# 顺序不能乱的原因

> 开时钟 →时钟源→时基单元→定时器中断使能→NVIC→TIM_Cmd 开启定时器 如果提前 TIM_Cmd 打开定时器，定时器已经跑起来，配置还没做完，会出现异常中断。

## 快速记忆区分

- `TIM_TimeBaseInit`：配置 PSC、ARR 计数器硬件
- `TIM_ITConfig`：定时器外设，允许产生中断信号
- NVIC_Init：内核，允许这个中断信号进到 CPU
- `TIM_Cmd`：打开计数器，CNT 开始往上数
