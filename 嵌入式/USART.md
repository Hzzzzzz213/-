# 时钟同步 / 异步

一句话：**同步：有一根单独的时钟线，双方跟着同一个时钟节拍干活；异步：没有共用时钟线，双方各自用自己的时钟，靠电平 / 边沿来识别信号。**
![[USART.png]]
•串口是一种应用十分广泛的通讯接口，串口成本低、容易使用、通信线路简单，可实现两个设备的互相通信

•单片机的串口可以使单片机与单片机、单片机与电脑、单片机与各式各样的模块互相通信，极大地扩展了单片机的应用范围，增强了单片机系统的硬件实力
![[USART-1.png]]
•电平标准是数据1和数据0的表达方式，是传输线缆中人为规定的电压与数据的对应关系，串口常用的电平标准有如下三种：

==•TTL电平：+3.3V或+5V表示1，0V表示0==

•RS232电平：-3~-15V表示1，+3~+15V表示0

•RS485电平：两线压差+2~+6V表示1，-2~-6V表示0（差分信号）
•波特率：串口通信的速率（如1000bps，1秒发1000位）

•起始位：标志一个数据帧的开始，固定为低电平（控线高电平）

•数据位：数据帧的有效载荷，1高电平，0低电平，低位（权重最小）先行

•校验位：用于数据验证，根据数据位计算得来

•停止位：用于数据帧间隔，固定为高电平，为下一个起始位准备

•USART（Universal Synchronous/Asynchronous Receiver/Transmitter）通用同步/异步收发器

•USART是STM32内部集成的硬件外设，可根据数据寄存器的一个字节数据自动生成数据帧时序，从TX引脚发送出去，也可自动接收RX引脚的数据帧时序，拼接为一个字节数据，存放在数据寄存器里

•自带波特率发生器，最高达4.5Mbits/s

•可配置数据位长度（8/9）、停止位长度（0.5/1/1.5/2）

•可选校验位（无校验/奇校验/偶校验）

•支持同步模式、硬件流控制、DMA、智能卡、IrDA、LIN


•STM32F103C8T6 USART资源： USART1、 USART2、 USART3

## 发送流程

CPU/DMA 把数据写入 **TDR 发送数据寄存器** → 自动转到**发送移位寄存器**（置标志位TXE（Empty））→ 一位一位移出（向右移位所以低位先行），经过编解码模块，从 TX 引脚串行发出去。

> TDR 是 “缓存”，移位寄存器才是真正往外逐比特发送。
   TXE发送寄存器数据空，置1就可以将下一个数据写入TDR，数据其实还没发出去
   
## 接收流程

RX 引脚收到串行比特 → 进入**接收移位寄存器**，把串行数据拼成完整字节 → 存入 **RDR 接收数据寄存器**（置标志位RXNE） → CPU/DMA 读 DR 拿到数据。
