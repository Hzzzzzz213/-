
我先用一句话总结：**回调函数就是一个“被动触发”的函数。你提前写好“收到数据后要干什么”，硬件一旦收满数据，底层就会自动来调用它。**



### 一、 回调函数的作用
1. **解放 CPU（非阻塞）**：以前你在 `while(1)` 里用 `HAL_UART_Receive`（阻塞接收），程序死等数据，CPU 啥也干不了。现在用了回调，你只需要喊一句“开始接收”，然后 CPU 就可以去干别的事（比如闪烁其他灯、计算数据）。等数据真到了，硬件会自动打断 CPU，执行这个回调函数。
2. **处理业务逻辑**：它是“数据到达”和“你写的业务代码（亮灯）”之间的桥梁。

---

### 二、 结合你的截图，逐行讲解使用方式



#### 第 1 步：数据回显（验证通信）
```c
HAL_UART_Transmit_IT(&huart2, receiveData, 2);
```
*   收到的数据（`receiveData`）立刻通过中断方式发回给电脑。这方便你在串口助手里看到自己到底发了啥，确认没发错。

#### 第 2 步：解析指令（提取“开关”状态）
```c
GPIO_PinState state = GPIO_PIN_SET;
if (receiveData[1] == '0'){
    state = GPIO_PIN_RESET;
}
```
*   默认是高电平。如果发来的第 2 个字符是 `'0'`，就把状态改成低电平（关灯/开灯，取决于你的硬件）。
*   这里你保留了之前的经典逻辑，**非常好**。

#### 第 3 步：执行动作（控制硬件）
```c
if (receiveData[0] == 'R'){
    HAL_GPIO_WritePin(LED_RED_GPIO_Port, LED_RED_Pin, state);
} else if (receiveData[0] == 'G'){
    ...
} else if (receiveData[0] == 'B'){
    ...
}
```
*   根据收到的第 1 个字符，选择控制红、绿、蓝哪个灯。并且把刚才算好的 `state` 传给写引脚的函数。

#### ==第 4 步：重新开启接收（极其重要！）==
```c
HAL_UART_Receive_IT(&huart2, receiveData, 2);
```
*   **这是整个函数最容易被忽略的一点**。HAL 库的 `_IT` 接收是“一次性”的。收满 2 个字节进了这个回调后，接收就自动关闭了。如果你不在末尾再次调用这行代码，你的串口就成“聋子”了，再也收不到下一次数据。


# HAL_UART_RxCpltCallback 笔记

## 全称

Rx Complete Callback，**串口接收完成回调函数**

```c
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart);
```

## 触发条件

仅在使用下面两个接收API时才会进入：

1. `HAL_UART_Receive_IT()` 中断接收
2. `HAL_UART_Receive_DMA()` 普通DMA接收

> ✅ 触发规则：**收到预设的全部字节数，才进入回调** ❌ 串口总线空闲不会触发，没凑够数量就一直等待

## 核心作用

接收任务完成后，HAL库自动调用该函数，在这里编写**收到数据之后要执行的逻辑** 常用功能：

- 串口数据转发（截图示例：收到后从另外一路串口发出去）
- 固定长度指令解析、控制外设
- 向上位机回复应答、回显数据

## 特点

1. 无长度参数，默认本次收到的就是你设置好的接收字节数
2. 属于**单次接收任务**：触发一次之后接收就停止；想要持续接收，必须在回调内重新启动接收
3. 适合：**固定帧长协议**
4. 不适合：不定长串口数据

## 和 HAL_UARTEx_RxEventCallback 区分（重点）

|回调函数|配套API|触发时机|参数|适用场景|
|---|---|---|---|---|
|HAL_UART_RxCpltCallback|HAL_UART_Receive_IT / HAL_UART_Receive_DMA|收满指定字节|只有huart，无Size|固定长度帧|
|HAL_UARTEx_RxEventCallback|HAL_UARTEx_ReceiveToIdle_DMA|收满 或 串口空闲|huart + Size（实际收到字节）|不定长帧|

> ⚠️ 二者互斥：使用ReceiveToIdle_DMA，不会进入RxCpltCallback

## 标准可用模板

```c
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if(huart->Instance == USART1)
    {
        // 收到预设长度数据后执行业务
        HAL_UART_Transmit_DMA(&huart2, receiveData, 2);

        // 【必加】重启接收，持续等待下一组数据
        HAL_UART_Receive_DMA(&huart1, receiveData, 2);
    }
}
```
