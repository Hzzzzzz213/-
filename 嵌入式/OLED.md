### 函数：`OLED_ShowString(行号, 列号, "字符串");`

```
OLED_ShowString(1, 1, "Freq:00000Hz");
OLED_ShowString(2, 1, "Duty:00%");
```

#### 2. 为什么写固定 0？

**0 当做占位格子**，后面`ShowNum`把测量出来的数值填进这些 0 的位置，屏幕排版整齐不乱。

- 5 个`0`：给频率预留 5 位数字位置，最多显示 99999Hz
- 2 个`0`：给占空比预留 2 位数字位置，最多显示 99%

> 后续一般会搭配这两句：

```
OLED_ShowNum(1,6,IC_GetFreq(),5); //第1行第6列，写5位频率数字，覆盖00000
OLED_ShowNum(2,6,IC_GetDuty(),2); //第2行第6列，写2位占空比数字，覆盖00
```
