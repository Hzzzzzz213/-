### 判断缓冲区是空还是满
前提约定：

- `wr`：==下一个要写入的空位==
- `rd`：==下一个要读取的有效数据位置==
- 数组长度 `BUF_LEN`，**永远保留 1 个位置不存有效数据**，用来区分空、满

✅ **缓冲区为空：`wr == rd`** 读写指针指向同一个位置，没有数据可以读。

✅ **缓冲区为满：`(wr + 1) % BUF_LEN == rd`** 写指针再往后走一步，就撞上读指针，不能再写。

## 补充考点

1. 代价：BUF_LEN=64，最多只能存 63 个字节，牺牲一格空间；
2. 为什么不能只用 `wr == rd` 判断？ 写满之后 wr 绕回，也会等于 rd，分不清到底是空还是满，产生歧义；
3. 取模 `%BUF_LEN` 作用：指针走到末尾自动绕回开头，实现环形。

## 速记表格

表格

| 状态  | 判断条件                       |     |
| --- | -------------------------- | --- |
| 空   | `wr == rd`                 |     |
| 满   | `(wr + 1) % BUF_LEN == rd` |     |
| 可写  | `(wr + 1) % BUF_LEN != rd` |     |
| 可读  | `wr != rd`                 |     |
|     |                            |     |
### 读和写
```c
#include <stdint.h>

#define BUF_LEN 64                  // 环形缓冲区总长度
uint8_t ring_buf[BUF_LEN];          // 缓冲区数组
uint16_t wr = 0, rd = 0;            // wr：写指针(下一个待写空位)；rd：读指针(下一个待读数据)

/**
 * @brief  环形缓冲区写1字节
 * @param  dat：要写入的数据
 * @retval 0写入成功，1缓冲区已满写入失败
 */
uint8_t ring_write(uint8_t dat)
{
    // 判断：(wr+1)取模后不等于rd → 没满，可以写
    if( (wr + 1) % BUF_LEN != rd )
    {
        ring_buf[wr] = dat;         // 写入wr指向的空位
        wr = (wr + 1) % BUF_LEN;    // 写指针后移，到末尾自动绕回0
        return 0;
    }
    return 1;   // 缓冲区满，写入失败
}

/**
 * @brief  环形缓冲区读1字节
 * @param  pdat：读出数据的存放地址（输出参数）
 * @retval 0读取成功，1缓冲区为空读取失败
 */
uint8_t ring_read(uint8_t *pdat)
{
    // wr != rd 代表缓冲区有数据
    if( wr != rd )
    {
        *pdat = ring_buf[rd];       // 取出rd指向的数据
        rd = (rd + 1) % BUF_LEN;    // 读指针后移，到末尾自动绕回0
        return 0;
    }
    return 1;   // 缓冲区空，读取失败
}
```
