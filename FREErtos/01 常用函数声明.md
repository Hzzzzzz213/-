### 一、 任务管理（Task）

```c
// 1. 创建任务
BaseType_t xTaskCreate( TaskFunction_t pxTaskCode,
                        const char * const pcName,
                        const configSTACK_DEPTH_TYPE usStackDepth,
                        void * const pvParameters,
                        UBaseType_t uxPriority,
                        TaskHandle_t * const pxCreatedTask );

// 2. 删除任务（传入 NULL 代表删除自身）
void vTaskDelete( TaskHandle_t xTaskToDelete );

// 3. 相对延时（按系统节拍）
void vTaskDelay( const TickType_t xTicksToDelay );

// 4. 绝对延时（用于严格周期性任务）
void vTaskDelayUntil( TickType_t * const pxPreviousWakeTime,
                      const TickType_t xTimeIncrement );

// 5. 获取当前系统节拍数
TickType_t xTaskGetTickCount( void );
```
**语法解析**：
*   返回 `BaseType_t`：用于告诉你任务建没建成功（返回 `pdPASS` 或 `errCOULD_NOT_ALLOCATE_REQUIRED_MEMORY`）。
*   注意 `xTaskCreate` 的最后一个参数：`TaskHandle_t * const pxCreatedTask`，这是一个**指向句柄的指针**。如果不需要外部控制该任务，填 `NULL` 即可。
*   返回 `void`：这些函数只执行动作，不汇报结果。

### 二、 队列（Queue）

```c
// 1. 创建队列
QueueHandle_t xQueueCreate( UBaseType_t uxQueueLength,
                            UBaseType_t uxItemSize );

// 2. 发送数据（默认发往队尾）
BaseType_t xQueueSend( QueueHandle_t xQueue,
                       const void * pvItemToQueue,
                       TickType_t xTicksToWait );

// 3. 接收数据
BaseType_t xQueueReceive( QueueHandle_t xQueue,
                          void * const pvBuffer,
                          TickType_t xTicksToWait );
```
**语法解析**：
*   创建函数返回 `QueueHandle_t`（队列句柄），后续收发必须把这个句柄传进去。
*   发送和接收返回 `BaseType_t`（`pdTRUE` 或 `pdFALSE`），用于判断是否超时。
*   `const void * pvItemToQueue`：发送时传入数据的**地址**（要加上 `&` 取地址符）。
*   `void * const pvBuffer`：接收时传入一个**缓冲区的地址**，用来存放取出来的数据。
*   `xTicksToWait`：阻塞时间，填 `portMAX_DELAY` 表示死等。

### 三、 信号量 / 互斥量（Semaphore / Mutex）

*(注意：在较新的 FreeRTOS 版本中，宏被替换成了真实的函数声明，但底层逻辑一致)*

```c
// 1. 创建二值信号量（用于同步）
SemaphoreHandle_t xSemaphoreCreateBinary( void );

// 2. 创建互斥量（用于保护共享资源）
SemaphoreHandle_t xSemaphoreCreateMutex( void );

// 3. 获取信号量（Take）
BaseType_t xSemaphoreTake( SemaphoreHandle_t xSemaphore,
                           TickType_t xBlockTime );

// 4. 释放信号量（Give）
BaseType_t xSemaphoreGive( SemaphoreHandle_t xSemaphore );
```
**语法解析**：
*   创建函数返回 `SemaphoreHandle_t` 类型（本质也是指针句柄）。
*   `xSemaphoreTake` 和 `xSemaphoreGive` 返回 `BaseType_t` 状态码。

### 四、 事件组（Event Group）

```c
// 1. 创建事件组
EventGroupHandle_t xEventGroupCreate( void );

// 2. 设置事件位（相当于按开关）
EventBits_t xEventGroupSetBits( EventGroupHandle_t xEventGroup,
                                const EventBits_t uxBitsToSet );

// 3. 等待事件位（相当于等开关被按下）
EventBits_t xEventGroupWaitBits( const EventGroupHandle_t xEventGroup,
                                 const EventBits_t uxBitsToWaitFor,
                                 const BaseType_t xClearOnExit,
                                 const BaseType_t xWaitForAllBits,
                                 TickType_t xTicksToWait );
```
**语法解析**：
*   注意！事件组的设置和等待返回值是 **`EventBits_t`**（通常是 `uint32_t`），它返回的是当前事件组中**所有标志位的状态**（而不是简单的 pdTRUE/pdFALSE）。
*   `xEventGroupWaitBits` 需要传入**你要等哪几个位**（`uxBitsToWaitFor`）、**等到后要不要清零**（`xClearOnExit`）、以及**是等所有位还是等任意一个位**（`xWaitForAllBits`）。

### 五、 ⚠️ 中断专用声明（带 FromISR 后缀）

在中断函数中调用，**绝不能**调用上面的普通版本，必须用这些：

```c
// 1. 中断中发送队列
BaseType_t xQueueSendFromISR( QueueHandle_t xQueue,
                              const void * pvItemToQueue,
                              BaseType_t * const pxHigherPriorityTaskWoken );

// 2. 中断中释放信号量
BaseType_t xSemaphoreGiveFromISR( SemaphoreHandle_t xSemaphore,
                                  BaseType_t * const pxHigherPriorityTaskWoken );
```
**语法解析**：
*   **没有阻塞时间参数**！中断必须立刻返回，所以不能传 `xTicksToWait`。
*   多了一个 `BaseType_t * const pxHigherPriorityTaskWoken` 参数：你必须定义一个变量传它的地址进去。如果该函数唤醒了更高优先级的任务，这个变量会被置为 `pdTRUE`，你在中断退出前必须调用 `portYIELD_FROM_ISR(变量名)` 来触发任务切换。

### 六、 临界区保护（宏定义）

这些通常是用宏（`#define`）写的，看起来像函数声明：

```c
// 任务中进入/退出临界区（关/开中断）
void taskENTER_CRITICAL( void );
void taskEXIT_CRITICAL( void );

// 中断中进入/退出临界区
UBaseType_t taskENTER_CRITICAL_FROM_ISR( void );
void taskEXIT_CRITICAL_FROM_ISR( UBaseType_t uxSavedInterruptStatus );
```

---

### 💡 终极语法规律总结（背下这4句，不再怕查文档）

1.  **建东西**：返回 `xxxHandle_t`（句柄），名字带 `Create`。
2.  **发东西/放东西**：返回 `BaseType_t`（状态码），名字带 `Send` 或 `Give`。
3.  **收东西/拿东西**：返回 `BaseType_t`，名字带 `Receive` 或 `Take`，参数里有 `(void * 缓冲区, 等待时间)`。
4.  **中断里用**：函数名后缀加 `_FromISR`，参数多一个 `pxHigherPriorityTaskWoken`。
