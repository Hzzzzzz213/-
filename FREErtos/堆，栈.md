# 1. `void *my_malloc(...)` 为什么看起来是 void 却有返回值？

> 重点拆分：`void *` 是一个**整体类型：void 指针（通用指针）**，不是 `void`（无返回值）！

- `void my_func()`：返回值写单独 `void` → **没有返回值，不能 return 任何数据**
- `void *my_func()`：返回值类型是 `void*` → **返回一个内存地址（指针）**
