

| 文件       | 优点                                       | 缺点                     |
| -------- | ---------------------------------------- | ---------------------- |
| heap_1.c | 分配简单，执行时间固定、可预测                          | 只分配无头部，**不能释放内存**      |
| heap_2.c | 动态分配，最佳匹配算法                              | 释放后不会合并，产生内存碎片；分配耗时不确定 |
| heap_3.c | 直接调用标准库`malloc/free` 一般不用                | 速度慢、时间不确定；依赖编译器库       |
| heap_4.c | 空闲块自动合并，大幅减少内存碎片                         | 执行时间不确定                |
| heap_5.c | 继承 heap4（自动合并空闲块）；支持**多处不连续内存区域**，外部拓展空间 | 执行时间不确定                |
## 8.3 Heap 相关函数

### 8.3.1 pvPortMalloc / vPortFree

**函数原型**

```
void * pvPortMalloc( size_t xWantedSize );
void vPortFree( void * pv );
```

**作用**

- pvPortMalloc：分配堆内存；分配失败返回`NULL`
- vPortFree：释放堆内存

### 8.3.2 xPortGetFreeHeapSize

**函数原型**

```
size_t xPortGetFreeHeapSize( void );
```

**作用**：获取当前剩余空闲堆大小，用于内存优化。

> 示例：所有内核对象创建完成后调用，返回 2000，则`configTOTAL_HEAP_SIZE`可以减少 2000。 ⚠️ 限制：`heap_3`不支持该函数。

### 8.3.3 xPortGetMinimumEverFreeHeapSize

**函数原型**

```
size_t xPortGetMinimumEverFreeHeapSize( void );
```

**作用**：返回程序运行期间，堆空闲内存的历史最小值（内存谷底值，用于排查内存泄漏）。 ⚠️ 限制：仅`heap_4`、`heap_5`支持。

### 8.3.4 malloc 失败钩子函数 vApplicationMallocFailedHook

#### 源码逻辑简述

`pvPortMalloc`内部：分配内存失败（`pvReturn == NULL`）时，判断宏`configUSE_MALLOC_FAILED_HOOK`是否为 1，满足则调用钩子函数。

```c
#if ( configUSE_MALLOC_FAILED_HOOK == 1 )
{
    if( pvReturn == NULL )
    {
        extern void vApplicationMallocFailedHook( void );
        vApplicationMallocFailedHook();
    }
}
#endif
```

#### 使用条件

1. `FreeRTOSConfig.h`中将`configUSE_MALLOC_FAILED_HOOK`配置为`1`
2. 用户自行实现`vApplicationMallocFailedHook`函数
3. `pvPortMalloc`内存分配失败时自动触发
