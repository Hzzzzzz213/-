使用队列整体流程：**创建队列 → 写队列 → 读队列 → 删除队列**

队列创建分为两种方式：**动态内存分配、静态内存分配**

## 1. 动态分配：`xQueueCreate()`

> 队列所需内存由函数内部自动动态申请 函数原型：

```c
QueueHandle_t xQueueCreate( UBaseType_t uxQueueLength, UBaseType_t uxItemSize );
```

表格

|参数|说明|
|---|---|
|uxQueueLength|队列长度，队列最多能存放多少个数据项 (item)|
|uxItemSize|单个数据项大小，单位：字节|
|返回值|非 0：成功，返回队列句柄，后续通过句柄操作队列NULL：失败，通常是内存不足|

---

## 2. 静态分配：`xQueueCreateStatic()`

> 队列的内存需要用户提前手动定义、分配好 函数原型：

```c
QueueHandle_t xQueueCreateStatic(
    UBaseType_t uxQueueLength,
    UBaseType_t uxItemSize,
    uint8_t *pucQueueStorageBuffer,
    StaticQueue_t *pxQueueBuffer
);
```

表格

| 参数                    | 说明                                                            |
| --------------------- | ------------------------------------------------------------- |
| `uxQueueLength`       | 队列长度，队列最多能存放多少个数据项 (item)                                     |
| uxItemSize            | 单个数据项大小，单位：字节                                                 |
| pucQueueStorageBuffer | 指向`uint8_t`数组，用来存放队列里的有效数据数组最小尺寸：`uxQueueLength * uxItemSize` |
| pxQueueBuffer         | 指向`StaticQueue_t`结构体变量，用来保存队列本身的控制结构                          |
| 返回值                   | 非 0：成功，返回队列句柄NULL：失败，`pxQueueBuffer`传了 NULL                   |

### 静态创建示例代码

```
#define QUEUE_LENGTH 10
#define ITEM_SIZE sizeof( uint32_t )

// 保存队列控制结构体
StaticQueue_t xQueueBuffer;
// 队列数据存储缓冲区
uint8_t ucQueueStorage[ QUEUE_LENGTH * ITEM_SIZE ];

void vATask( void *pvParameters )
{
    QueueHandle_t xQueue1;
    // 创建静态队列
    xQueue1 = xQueueCreateStatic( QUEUE_LENGTH,
                                  ITEM_SIZE,
                                  ucQueueStorage,
                                  &xQueueBuffer );
}
```

## ✅ 两者对比小结

- `xQueueCreate`：简单省心，自动申请堆内存；RAM 紧张时容易分配失败
- `xQueueCreateStatic`：内存由用户全局 / 静态定义，不占用堆，内存可控；代码多几行，适合高可靠、禁止动态内存的场景
