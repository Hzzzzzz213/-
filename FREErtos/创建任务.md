# TCB — Task Control Block，任务控制块

一句话：**保存一个任务全部信息的结构体，每个任务都有独立的 TCB**

## 通俗理解

每个任务 = 1 个 TCB + 任务栈 TCB 就是这个任务的**个人档案袋**。 档案里记录：任务名字、优先级、栈起始地址、栈剩余空间、任务状态（就绪 / 阻塞 / 挂起）、链表节点等。

## 怎么来的

调用`xTaskCreate()`创建任务的时候，内核底层调用`pvPortMalloc`自动申请一块内存，生成 TCB 结构体。 任务删除`vTaskDelete()`时，TCB 内存会被释放（heap1 除外）。

## TCB 里面存什么（核心成员）

- 任务栈指针 pxTopOfStack：保存任务切换时的 CPU 寄存器
- 任务优先级 uxPriority
- 任务状态：就绪、阻塞、挂起
- 链表节点 ListItem_t：用来挂入就绪 / 阻塞链表（前面学的 list）
- 任务名称 pcTaskName

## 作用

任务切换的时候，内核读取 / 修改 TCB 里的信息，保存上一个任务现场，加载下一个任务现场。
