# # 什么时候必须手动写 `\0`，什么时候不用

## 一、不用手动写 `\0` 的场景（系统自动补）

### 1. 直接用双引号字符串字面量 `"xxx"`

```
char* p = "abc";
char arr[] = "abc";
```

内存自动存：`a b c \0`，末尾零字节编译器自动加上，不用你写。

### 2. 字符数组长度留空，用字符串赋值
```
char arr[] = "test";
```

数组长度自动变成 5，最后一位存 `\0`。

### 3. 标准输入函数 `scanf("%s") / gets` 读取字符串

c

运行

```
char buf[20];
scanf("%s", buf);
```

输入完成后，函数会自动在读取内容末尾追加 `\0`。

---

## 二、**必须手动添加 `\0`** 的场景

### 场景 1：大括号逐个初始化字符，数组刚好塞满字符，没留空位



```
// 错误：4个字符填满4格，无位置存 \0，不是字符串
char arr[4] = {'t','e','s','t'};

// 正确：多留1格，手动写 \0
char arr[5] = {'t','e','s','t','\0'};
```

### 场景 2：分段赋值字符数组、手动填充字符



```
char buf[10];
buf[0] = 'h';
buf[1] = 'i';
// 不加下面这行就不是字符串，%s打印乱码
buf[2] = '\0';
```

### 场景 3：从文件 / 内存拷贝字符到数组，手动拼接字符


```
char temp[20];
// 拷贝3个字符进去
temp[0] = 'a';
temp[1] = 'b';
temp[2] = 'c';
temp[3] = '\0'; // 手动补结束符，才能当字符串使用
```

### 场景 4：自定义函数构造字符串、截断字符串

比如截取前 2 个字符作为新字符串，末尾必须补零：



```
char str[10] = "hello";
char sub[5];
sub[0] = str[0];
sub[1] = str[1];
sub[2] = '\0'; // 截断，构成合法字符串 "he"
```

### 场景 5：动态内存分配（malloc）存放字符串

malloc 只分配纯内存，不会自动补 `\0`：

c

运行

```
char* p = (char*)malloc(10);
p[0] = 'x';
p[1] = 'y';
p[2] = '\0'; // 必须手动加，否则不是字符串
```

---

## 三、核心判断规则 💡

只要满足下面任意一条，**不用写 `\0`**：

1. 赋值源是双引号包裹的字符串 `"xxx"`；
2. 用 `scanf("%s")` / `fgets` 等标准字符串读取函数填充数组。

其他所有**手动一个一个给数组元素赋值字符**的情况，想让它变成能使用 `%s`、`strlen`、`strcpy` 的字符串，**最后一位必须手动写 `'\0'`**。

## 补充：不加 \0 的后果

调用字符串相关函数（`printf("%s")`、`strlen`、`strcat`）时，程序会一直向后读取内存，直到随机碰到内存里的 0，出现：

- 输出一堆乱码
- 内存越界，程序崩溃
