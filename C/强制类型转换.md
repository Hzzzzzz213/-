**定义**：程序员主动告诉编译器：“别管它原来是什么类型，你就按我指定的类型来处理它。”  
**本质**：内存里的数据没有任何变化，变的只是**编译器看待这段内存的视角**。

### 1. 基本语法

(目标类型) 变量或表达式

### 2. 两大使用场景

#### 🔴 场景一：数值转换（容易丢失精度）



```c
int a = 5, b = 2;
// 直接 a/b 结果是 2（整数除法）
float result = (float)a / b; // 强转 a 为 float，结果 2.5
float pi = 3.1415;
int num = (int)pi; // 强转 float 为 int，结果是 3（砍掉小数）
```

#### 🔴 场景二：指针转换（嵌入式最常见）

`void *`（万能指针）无法直接取值，必须强转。

```c

int num = 100;
void *p = &num;             // p 指向 num，但不知道类型
int *int_p = (int *)p;      // 强转为 int 指针
int value = *int_p;         // 成功取出 100
```

## 四、 ⚠️ 避坑指南（切勿瞎转）

编译器不管你转得对不对，但如果你转错了，程序会**直接崩溃（死机/段错误）**。

**错误示例：张冠李戴**


```c
int a = 100;
// 错误：把 int 的地址（4字节），强转成了大结构体指针（可能十几个字节）
struct Info *info = (struct Info *)&a; 
// 崩溃！程序会去读 a 后面不属于它的内存（越界）
printf("%s", info->str); 

```
**总结**：

- 强制类型转换是**“强扭的瓜”**，编译器会乖乖闭嘴。
    
- 但你自己必须清楚**内存里装的到底是什么**。在 FreeRTOS 里，只要传进来的 `pvParameters` 确实是那个结构体的地址，强转回来就绝对安全。
