1 字节（Byte）= 8 位（bit）

| 变量        | 32 位系统 | 64 位系统 | 备注           |
| --------- | ------ | ------ | ------------ |
| char c    | 1      | 1      | 字符           |
| short b   | 2      | 2      | 短整型          |
| int a     | 4      | 4      | 整型           |
| long i    | 4      | 8      | long 是平台相关类型 |
| char *p1  | 4      | 8      | 指针           |
| short *p2 | 4      | 8      | 指针           |
| int *p3   | 4      | 8      | 指针           |
| long *p4  | 4      | 8      | 指针           |
```c
uint8_t   // uint8_t  = unsigned char      1字节
uint16_t  // uint16_t = unsigned short     2字节
uint32_t  // uint32_t = unsigned int        4字节
uint64_t  // 32位：unsigned long long；64位：unsigned long   8字节
```
