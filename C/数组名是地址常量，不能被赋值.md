```c
char a[10];   // 在栈上开辟一块连续内存，数组名 a 代表这块数组的首地址
a = "lyh";    // ❌ 非法！
```

1. `char a[10]` 定义数组后，**`a` 是常量地址**，编译器规定：数组名不能作为左值（不能放在 `=` 左边被修改）。

> 左值：可以被赋值的变量，要有可修改的内存空间。常量地址不能被赋值。

2. `"lyh"` 是**字符串字面量**，存放在只读常量区，表达式的值是字符串首字符 `'l'` 的地址。 你这句代码想做的事情：试图把字符串常量的地址，覆盖写到数组名 `a` 这个常量上，C 语法不允许。

## ✅ 正确写法

### 写法 1：定义时直接初始化（推荐）

```
char a[10] = "lyh";
```

> 这不是赋值！这是**初始化**。编译器会把常量区的`'l','y','h','\0'`拷贝到数组 a 对应的内存空间。

### 写法 2：定义之后，用 strcpy 拷贝字符串

```
#include <string.h>
char a[10];
strcpy(a, "lyh");
```

> strcpy：把常量字符串的内容，逐个字符复制到数组 a 的内存里。**修改的是数组里面的数据，不是数组名 a**。

### 写法 3：单个字符赋值

```
char a[10];
a[0]='l';
a[1]='y';
a[2]='h';
a[3]='\0'; // 手动加字符串结束符
```

## 容易混淆的对比（指针可以）

```
char *p;
p = "lyh"; // ✅ 合法！
```

`p` 是**字符指针变量**，变量可以存放地址。这句是把字符串字面量的首地址存到指针变量 p 中。

> ⚠️ 注意：这种方式`"lyh"`在只读内存，不能通过`p`修改字符串内容。
