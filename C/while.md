
| 写法                                             | 含义             | 特点                            | 适用场景                    | 注意坑                     |
| ---------------------------------------------- | -------------- | ----------------------------- | ----------------------- | ----------------------- |
| `while(1)`<br><br>`{ 代码; }`                    | 死循环，一直执行大括号内代码 | 永远不会自动退出                      | FreeRTOS 任务、裸机 main 主循环 | 里面一定要加延时 / 阻塞，不然 CPU 占满 |
| `while(flag);`                                 | 空循环忙等          | 带分号！只判断，不执行别的代码，CPU 空转        | 等待标志清零、硬件就绪             | 分号不能丢；RTOS 不推荐，浪费 CPU   |
| `while(条件)`<br><br>`{ 代码; }`                   | 条件为真，执行循环体     | 条件不满足就退出循环                    | 循环读取、遍历、多次处理数据          | 条件记得会变化，防止死循环           |
| `while(1)`<br><br>`{ if(ok) break; }`          | 循环等待，满足条件跳出    | break 直接跳出 while 循环           | 等待事件、等待指令               | break 只跳出当前一层 while     |
| `while(1)`<br><br>`{ if(skip) continue; 业务; }` | 跳过本次循环         | continue：直接回到 while 判断，后面代码不跑 | 过滤某些情况，不执行本次业务          | 不会跳出循环，只是跳过本轮           |
| `while(外设标志)`<br><br>`{}`                      | 等待外设就绪         | 读取寄存器标志位轮询                    | 串口接收、ADC、SPI 等待完成       | 注意寄存器标志需要软件清零           |
