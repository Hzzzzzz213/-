## 一、`#define` 宏定义
、
- **本质**：预处理阶段的**文本替换**，不做任何语法检查，只是简单的字符串替换。
- **作用**：给常量、表达式甚至代码片段起别名，方便修改和阅读。
- **例子**：
    
    c
    
    运行
    
    ```
    #define ABC 12345
    int a = ABC; // 预处理后直接变成 int a = 12345;
    ```
    
- **特点**：
    
    - 只做文本替换，不关心类型，所以容易出 bug（比如运算符优先级问题）。
    - 作用域是整个文件，预处理时直接替换，运行时没有额外开销。
    - 可以定义带参数的宏（类似函数，但不是函数）。
    

---

## 二、`typedef` 类型别名

- **本质**：给**已有的数据类型**起一个新名字，是编译器层面的操作，属于 C 语言的类型系统。
- **作用**：简化复杂类型的书写，增强代码的可读性和可移植性。
- **例子**：
    
    c
    
    运行
    
    ```
    typedef unsigned char uint8_t;
    uint8_t a; // 等价于 unsigned char a;
    ```
    
- **特点**：
    
    - 是真正的类型，编译器会做类型检查，更安全。
    - 可以作用域控制（比如在函数内也能定义）。
    - 常用于结构体、指针、数组等复杂类型的别名，也用于跨平台代码（统一不同平台的类型名）。
    

---

## 三、核心区别对比表

表格

| 特性         | `#define`（宏定义）     | `typedef`（类型别名）               |
| ---------- | ------------------ | ----------------------------- |
| **阶段**     | 预处理阶段              | 编译阶段                          |
| **本质**     | 纯文本替换              | 给已有类型起别名                      |
| **类型安全**   | 无，不做语法 / 类型检查      | 有，编译器会做类型检查                   |
| **适用场景**   | 常量、简单文本替换、带参宏      | 类型简化、跨平台类型统一                  |
| **作用域**    | 默认整个文件（除非`#undef`） | 遵循 C 语言的作用域规则                 |
| **能否加限定词** | 不能（比如不能加`const`）   | 可以（比如`typedef const int ci;`） |
