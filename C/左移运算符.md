 C 语言中，`(1 << 0)` 是**位运算中的左移运算**：

- `<<`：左移运算符
    
- `1 << 0`：把整数 `1` 左移 `0` 位
    
- 左移 0 位等于没移动，所以结果是 `1`
    

例如：

c

int x = (1 << 0);  // x 等于 1

二进制理解：

text

1 的二进制：0000 0001
左移 0 位： 0000 0001  -> 仍然是 1

一般规律：

c

1 << n   // 等于 2 的 n 次方

所以：

c

1 << 0 == 1   // 2^0 = 1
1 << 1 == 2   // 2^1 = 2
1 << 2 == 4   // 2^2 = 4
1 << 3 == 8   // 2^3 = 8

这种写法常用于**位掩码**，表示“第 0 位为 1”。例如：

c

#define BIT0 (1 << 0)  // 二进制 00000001
#define BIT1 (1 << 1)  // 二进制 00000010
#define BIT2 (1 << 2)  // 二进制 00000100

总结：`(1 << 0)` 的意思就是 **把 1 左移 0 位，结果是 1**。
